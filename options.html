Click'n'Load Redirector

Redirect download requests to remote pyLoad or JDownloader

v1.0.3
Active Target URL http://127.0.0.1:9666

Target Server

Specify the hostname/IP, port, and protocol of your remote download manager.

Do not include "http://" or port here (pasted URLs are automatically cleaned).
Default: 9666
Use HTTPS if pyLoad or your reverse proxy is configured with an SSL/TLS certificate.

Redirection & Security

Configure HTTP headers and security bypass rules for redirected requests.

Replaces the HTTP Host header with 127.0.0.1:9666. Required by pyLoad and JDownloader to prevent host validation errors when accessed remotely.
Strips restrictive CSP headers from web pages to prevent browsers from blocking redirected requests to your configured host.

HTTP Basic Authentication

Optional credentials for servers protected with Basic Auth (only transmitted over HTTPS for security).

How It Works & Troubleshooting

How it works: Click'n'Load buttons on file sharing websites typically send requests to http://127.0.0.1:9666. This extension intercepts those calls and transparently redirects them to your configured target host, eliminating the need for an SSH port forward.

Mixed Content Warning: If the originating web page is loaded over HTTPS and your target is plain HTTP, browsers will block the active subresource as mixed content. To resolve this, configure HTTPS on your target host or allow insecure content for that site in your browser settings.
